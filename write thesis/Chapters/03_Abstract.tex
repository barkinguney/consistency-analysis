\chapter*{Abstract}
\label{Chap:Abstract}
This Master’s thesis presents the development of a computational framework for the uncertainty quantification and consistency analysis of chemical kinetic models. The work focuses on bridging the gap between raw experimental data and the systematic optimization of reaction mechanisms through the implementation of four core modules designed for the TUMKIN data infrastructure. First, an experimental shock tube IDT uncertainty estimation package was developed. This module quantifies uncertainty by combining random (Type-A) and systematic (Type-B) components. Systematic errors are evaluated through facility specific factors, allowing for a standardized assessment of non-idealities in shock tube measurements. Second, a reaction rate coefficient (RRC) uncertainty estimation package was implemented to programmatically assess kinetic parameter reliability. By collecting data across multiple libraries in the RMG database, the package evaluates rate coefficients over a standardized temperature grid. It utilizes a reparameterized log-linear Arrhenius model and Nonlinear Least Squares to derive temperature-dependent uncertainty factors ($f$) for each reaction. Third, the framework features robust Cantera IDT simulations to support the generation of training data. This module is capable of handling diverse experimental ignition definitions (e.g., $OH$ max, $dP/dt$ max, baseline intercept) to ensure high-fidelity comparisons between model and experiment. These simulations provide the foundation for sensitivity analysis, where impact factors are used to identify active reactions. Finally, these components were integrated with the Bound-to-Bound Data Collaboration (B2BDC) framework. By building quadratic surrogate models from the simulation results, the framework calculates a Scalar Consistency Measure (SCM) to evaluate the agreement between experimental datasets and the reaction mechanism. The function of the integrated pipeline is demonstrated through consistency checks on a joint Syngas/Hydrogen mechanism, identifying inconsistent data points and defining feasible parameter spaces. This work establishes a rigorous, automated path for data-driven kinetic model optimization.
